WhatsApp AI Bot

An AI-powered WhatsApp bot built on Node.js that automatically replies to incoming messages using an AI API. It handles common queries, responds in natural language, and can be extended for custom commands.

Project Focus

The bot listens for incoming messages, sends them to an AI API, and replies with a natural-language answer. It is designed to be lightweight, easy to deploy, and extendable with custom automation flows.

Built With

  • Node.js runtime
  • Express.js web server
  • AI API integration
  • WhatsApp Web automation
