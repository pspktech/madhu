InstaSaver

An open-source Android app built with Kotlin to download Instagram Reels, posts and profile pictures — fast, clean and privacy-focused.

Project Focus

The app keeps the flow simple: paste an Instagram link, tap download, and the media is saved to your device. No login, no ads, no tracking — just a lightweight tool that does one thing well.

Built With

  • Kotlin + Android Jetpack
  • MVVM architecture
  • Material Design 3
  • Open source on GitHub
